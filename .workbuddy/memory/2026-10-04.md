## 底部横白带真正的根因：--shell-max 小于视口（2026-10-04 续修）
- 用户反馈「底部横白带还是有」→ 说明前一轮判断的版心层只是症状之一
- **真根因**：`--shell-max: clamp(1120px, 88vw, 1560px)` 在 <1120px 的窗口下，
  容器 `.shell` 的 `max-width:1120px` 生效但父宽只有 1080 → **内容容器比视口窄**，
  `(100% - --shell-max)/2` 在 rule-line/canvas-fill 算式里被 `max(0px,…)` 夹平，
  两侧/底部因此露出 body 底色（`--color-surface: #faf9f7`，比 `--color-surface-elevated: #ffffff` 更暖）
- **修复**：`--shell-max` 下限 1120px → **100%**：`clamp(100%, 88vw, 1560px)`，
  保证「版心不小于视口」，窄窗口下容器自动贴边，宽屏行为不变（88vw 仍生效）
- 注意：`100%` 用于 max-width 是合法的（相对包含块），clamp 内混合 % 与 px 有效
- 说明：`.rule-line`/`.canvas-fill` 在 1280px 以下已隐藏，此修复针对**所有页面**的容器行为

## 底部白带 + 顶部被遮的最终根因：fixed 导航栏不占文档流（2026-10-04 三修，定稿）
- 用户反馈「还是没有 而且这个的模块是不是有一部分被导航栏遮挡住了」→ 前两轮都是治症状
- **真根因（一条规则同时解释两个症状）**：`AppHeader` 是 `position:fixed`，**不占文档流**，
  而 `.auth-split` 当时写的是 `min-h-[calc(100vh-var(--header-height))]`：
  - 高度少算 → 容器底边离视口底少 52px → **底部露白带**
  - 内容从 `y=0` 起排 → 左上墨色刊头被 fixed 栏压住 → **顶部被遮**
- **定稿写法（所有固定导航栏布局的通用解）**：
  ```html
  <div class="auth-split flex min-h-[100dvh] pt-[var(--header-height)]">
  ```
  即 **「用满 100dvh」+「pt 补偿栏高」**必须成对出现：
  前者保证文档高 = 视口高（不露底），后者把内容推到栏下（不被遮）。
  用 `calc(100vh - header)` 是错的——那是给**占流**导航栏（sticky/static）的写法。
- 已同步 LoginView + RegisterView；`dvh` 而非 `vh` 以适配移动端动态地址栏
- 同类页面参照：`/message` 的 `.msg-stage` 也是 100dvh + `pt-[var(--header-height)]`，思路一致
- **排查口诀**：凡是「底部多一条 / 顶部被压一条」且差值与 `--header-height`(52px) 吻合，
  先查该页容器是不是漏了 `pt-[var(--header-height)]` 或用错 `calc(100vh - …)`
