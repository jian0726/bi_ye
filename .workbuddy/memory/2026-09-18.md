## 前端 blog-web 开发与视觉重构（同日续）

### 关键 bug 修复
1. **DefaultLayout.vue 用 `<slot />` 渲染嵌套路由子页面 → main 永远空白**。
   嵌套路由必须用 `<RouterView>`，页面切换动画（Transition）也要包在内层 RouterView 上。
   此 bug 曾导致"首页渲染空白"误诊为数据/动画问题。
2. **useScrollReveal 只在挂载时观察一次**：异步数据渲染出的 .reveal 元素永远 opacity:0。
   修复：数据加载完成后 `await nextTick(); requestAnimationFrame(refresh)` 重新观察。
3. **agent-browser daemon 每次 Bash/PowerShell 调用后被杀**，页面退回 about:blank，
   之前的截图与 eval 全是空白页的假阴性。解决：写 `scripts/shot.mjs` / `scroll-shot.mjs`
   （Node spawnSync 在单进程内完成 open→wait→eval→screenshot 全流程）。
   注意：eval 表达式里不能含 `&&`（cmd 会吞掉），多行 JS 也会被拆断，必须单行。
4. 无头 Chrome 默认 prefers-color-scheme: dark，旧逻辑跟随系统导致黑屏观感；
   已改为强制默认浅色（用户要求浅色暖纸调，不要黑色）。

## 留言页切走后全站内容空白 bug 修复（同日续 10）

### 排查过程（浏览器复现取证）
- 自建复现脚本 scripts/repro-msg-blank.mjs + v2.mjs（agent-browser spawnSync 串行，

### 根因（减法实验确定）
- **MessageView.vue 模板根级注释**（`<template>` 下第一行是 `<!-- 弹幕墙留言板… -->`）

  新组件永不插入（emptyPlaceholder 停在 main 里）
- 排除项：100dvh/overflow:hidden（实验 2 改 min-height 仍卡）、滚动残留（全程 scrollY=0）、
  reveal 动画（masthead 无 reveal 也消失）、guard.ts（同步 return true）、全局样式泄漏（全 scoped）
