## 三、上线前必须替换的配置（`.env`）

```bash
cp .env.example .env
# 逐个生成强随机值
python -c "import secrets;print(secrets.token_urlsafe(24))"
```

必填 6 项：`MYSQL_ROOT_PASSWORD`、`MYSQL_PASSWORD`、`REDIS_PASSWORD`、
`MINIO_ROOT_USER`、`MINIO_ROOT_PASSWORD`、`JWT_SECRET`（≥32 字符）。

**`VERIFY_DEV_MODE` 必须为 `false`** —— 为 `true` 时验证码会写日志而不发短信/邮件。

## 四、已知限制（答辩可主动说明）

1. **无单元测试**：`blog-backend/src/test` 不存在，CI 里用 `-DskipTests`。功能验证靠 `scripts/test-readonly.py` / `test-authed.py` / `test-retest.py` 三份接口测试脚本（135 条用例）。
2. **历史中仍有两个 >50MB 的 jar**（`backend-before-ip2region.jar` 59MB、`-before-visitor-key.jar` 63MB），GitHub 已接受但会在推送时告警。如需彻底清除，可以对 `scripts/backup` 路径再做一次 `git filter-repo --path ... --invert-paths`。
3. **全文检索是 `title + summary` 的 LIKE**，未用 ngram，正文不参与搜索。
4. **文章版本历史未实现**（`t_article_history` 未建表）。
5. **留言板无回复能力**（设计定位为一次性留言），全站无评论功能。
6. **Redis 只用于两件事**：找回密码验证码、refresh token 撤销登记。浏览量、限流均不经 Redis。
