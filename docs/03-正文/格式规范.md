# 一、模板文件（必读）

> 长沙南方职业学院毕业设计正文排版规范  
> 来源：`暂定参考-22级_毕业设计正文要求.doc`

## 1.1 字体规范

| 位置 | 字体 | 字号 | 加粗 | 对齐 |
|---|---|---|---|---|
| 正文大标题 | 宋体 | 小三号 | 是 | 居中 |
| 一级标题（1.） | 宋体 | 小四号 | 是 | 左对齐 |
| 二级标题（1.1） | 宋体 | 小四号 | 否 | 左对齐 |
| 三级标题（3.1.1） | 宋体 | 小四号 | 否 | 左对齐 |
| 正文 | 宋体 | 五号 | 否 | 两端对齐 |
| 表格标题 | 黑体 | 五号 | 否 | 居中 |
| 表格内容 | 宋体 | 五号 | 否 | 居中 |
| 图标题 | 黑体 | 五号 | 否 | 居中 |
| 参考文献条目 | 宋体 | 五号 | 否 | 顶格 |
| 目录 | 宋体 | 小四号 | 否 | — |

## 1.2 图表规范

- **表**：标题置于表格上方，格式 `表1 XXXXXXXXX 表`
- **图**：标题置于图片下方，格式 `图1 XXXXXXXXX 图`
- 图表编号连续，表与图各自独立编号
- 图片大小需一致，截图需清晰

## 1.3 目录规范

- 自动生成，内容为宋体小四号
- 控制在 1 页内，需要时可调整行距
- 建议显示到二级标题（最多不超过三级）
- **不标页码**

## 1.4 页边距

| 位置 | 值 |
|---|---|
| 上 | 2.5 cm |
| 下 | 2.5 cm |
| 左 | 3.0 cm |
| 右 | 2.6 cm |

# 二、正文结构模板

```
封面
毕业设计诚信声明
目录
正文标题（居中，宋体小三，加粗）
  1.背景（宋体小四，加粗）
    1.1 开发背景
    1.2 开发目的和意义
  2.设计思路
    2.1 业务流程介绍
    2.2 技术方案
    2.3 工具设备要求
  3.设计内容
    3.1 系统详细设计
      3.1.1 系统概要说明
      3.1.2 系统流程图
    3.2 数据库设计
      3.2.1 数据库分析（必须含 ER 图）
      3.2.2 数据库表设计
    3.3 系统功能实现
      3.3.1 ~ 3.3.N 逐功能（截图 + 关键代码）
  4.小结
    4.1 毕业设计成果特点
    4.2 设计成果的实用价值或应用前景
    4.3 不足之处或遗留未予解决的问题
参考文献（不少于 5 篇，近 3 年）
附录 部分重要源码
查重报告
```

| 类型 | 格式 | 示例 |

| 期刊 | 作者.题名[J].刊名,年份,卷号(期号):起止页码. | 张粦雁.企业软件项目建设管理应用系统实施经验浅谈[J].厦门科技,2023(02):43-46. |
| 著作 | 著者.书名[M].出版地:出版者,出版年:起止页码. | — |

| 专利 | 专利所有者.专利题名[P].专利国别:专利号,发布日期. | — |

# 八、注意事项

1. 软件系统需求清晰、设计合理
2. 代码规范完整，各功能模块能正常运行
3. 正文结构完整，条理清晰，文字通畅，**截图清晰，图片大小一致**
4. 表述符合行业标准
5. 参考文献须为近 3 年且至少 5 篇
6. 附录与正文连续编页码，附录较多时可分附录 1、附录 2
